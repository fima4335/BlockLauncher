# BlockLauncher

Простой Minecraft-лаунчер на русском.

## Запуск

```bash
git clone https://github.com/fima4335/BlockLauncher.git
cd BlockLauncher
npm install
npm run dev
```

Нужны Node.js 18+ и Java (для новых версий MC — Java 21+).

## Возможности

- Русский интерфейс
- Инстансы
- Offline-аккаунты
- Автоустановка **Fabric** при создании инстанса
- Моды с Modrinth (+ required-зависимости)
- Вкладки: Играть, Аккаунты, Моды, Скины, Серверы, Настройки

## Как играть с модами

1. Аккаунты → добавь ник  
2. Создать инстанс → выбери версию → лоадер **Fabric**  
3. Моды → найди мод → Установить  
4. Играть  

Если Minecraft не стартует с ошибкой `UnsupportedClassVersionError` — обнови Java.
