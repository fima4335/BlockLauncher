# BlockLauncher 🧱

Minecraft лаунчер с **Mod Intelligence** — анализом зависимостей модов.

## Запуск

```bash
git clone https://github.com/fima4335/BlockLauncher.git
cd BlockLauncher
npm install
npm run dev
```

Нужны: **Node.js 18+**, **Java** в PATH.

## Возможности

- Electron UI
- Скачивание версий Minecraft
- Инстансы (отдельные папки)
- Offline-аккаунты
- Fabric / Forge / NeoForge
- Установка модов из Modrinth + required-зависимости
- Mod Intelligence (анализ зависимостей)

## Как пользоваться

1. **Аккаунты** → добавь offline-ник  
2. **Инстансы** → Создать → версия + лоадер  
3. **Моды (Modrinth)** → поиск → Установить  
4. **Играть**
