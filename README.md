# BlockLauncher

Простой рабочий лаунчер Minecraft.

## Установка и запуск

```bash
git clone https://github.com/fima4335/BlockLauncher.git
cd BlockLauncher
npm install
npm run dev
```

Нужно:
- Node.js 18+
- Java в PATH (`java -version`)

## Что умеет

- Offline-аккаунт
- Создание инстансов
- Скачивание версий Minecraft (Mojang)
- Запуск игры
- Установка модов с Modrinth (и required-зависимости)

## Как играть

1. Вкладка **Аккаунты** → добавь ник  
2. Вкладка **Играть** → **Создать** инстанс (выбери версию)  
3. Нажми **Играть** (версия скачается сама)  
4. По желанию: вкладка **Моды** → найди мод → Установить  

> Для модов нужен установленный лоадер (Fabric/Forge) в этой версии. В v1.0 основной режим — vanilla + ручное добавление модов под твой лоадер.
